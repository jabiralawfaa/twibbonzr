⚙️ mekanisme

Cara kerjanya, 5 langkah

Hasil reverse engineering cara kerja Twibbonzr — semuanya jalan di sisi browser.

1

Template = PNG berlubang

Bagian transparan di tengah adalah "lubang" tempat foto kamu tampil. Bagian solid jadi overlay.

2

Punya ID & link share

Saat dibuka, frontend fetch GET /api/templates/:slug lalu load PNG dari storage.

3

Foto dibaca lokal

Foto dibaca via FileReader → objek Image. Tidak dikirim ke mana pun.

4

Composite di Canvas

Urutan wajib: gambar foto dulu, baru PNG twibbon di atasnya. Alpha channel bekerja otomatis.

5

Download / simpan lokal

canvas.toDataURL() → download PNG, atau simpan ke galeri localStorage kamu.

🔒

Foto kamu nggak pernah ke server

Yang di-upload ke server hanya template twibbon-nya (PNG dari kamu). Foto orang-orang yang memakai twibbon? Diproses di canvas browser, disimpan di localStorage perangkat masing-masing, dan tidak masuk database. Hapus dari Galeri, ya, kalau mau hilang.
